# **App Name**: Creative Portfolio Hub

## Core Features:

- Portfolio Display: Display of portfolio items with images and descriptions based on the provided html.
- Interactive Timeline: Displays projects in a chronological timeline with descriptions and links to the code and deployed application based on the provided html.
- Skills Showcase: A scrollable grid based display of my various technical skills.
- Email Contact Form: A contact form for visitors to send messages directly to me.

## Style Guidelines:

- Primary color: Indigo (#52489C) for a professional and creative feel. 
- Background color: Light lavender (#F7F5FF), providing a soft and clean backdrop.
- Accent color: Orange-red (#FF5722), used sparingly for highlighting interactive elements. 
- Body font: 'Outfit', sans-serif; For main contents.
- Headline font: 'Outfit', sans-serif; For the titles and subtitles
- Font Awesome icons are extensively used. Neutral style in the same indigo as the primary color scheme.
- Clean and responsive layout, adapting seamlessly to different screen sizes.
