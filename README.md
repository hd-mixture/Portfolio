# [Darshan Prajapati's](https://www.hdmixture.site) Portfolio

This is the source code for my personal portfolio website, built with Firebase Studio. It showcases my skills and projects as a Creative Developer and Graphic Designer.

## About This Project

This portfolio is built with Next.js and styled with Tailwind CSS and ShadCN UI components. It features a modern, responsive design with smooth animations to highlight my work in web development, mobile applications, and graphic design.

## Tech Stack

- **Framework**: Next.js (with App Router)
- **Styling**: Tailwind CSS & ShadCN UI
- **Animations**: CSS Animations & Framer Motion
- **Deployment**: Firebase App Hosting

## Getting Started

To run this project locally:

1. Clone the repository.
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:9002](http://localhost:9002) in your browser to see the result.
